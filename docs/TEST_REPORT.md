## Устройство тестов

- `tests/conftest.py`: окружение задаётся до импорта `app` (SQLite tmp-файл, `PIPELINE_INLINE=true`, poller выключен, все провайдеры mock).
  - Каждый тест получает свою БД: копию файла-шаблона, созданного один раз через `init_db(drop=True)` и `seed_if_empty`. `lifespan` при этом отрабатывает полностью.
  - Провайдеры подменяются через `set_llm`, `set_search_provider` и `set_max_client`.
  - Клиенты — `httpx.AsyncClient(ASGITransport)` с cookie под каждой ролью. Сам логин проверяется отдельными тестами.
- `tests/nf_helpers.py`:
  - `check` и `data`: строгая проверка кода ответа; HTTP 501 превращается в xfail.
  - `require_pipeline`: пока пайплайн был заглушкой, такие тесты получали xfail.
  - Построение данных по контрактам прямо в БД (`researched`): API- и smoke-тесты не зависят от пайплайна.
  - `assert_clean_html`: проверка страницы на трейсбэки и внешние ресурсы.
- Хук в conftest: `NotImplementedError` превращается в xfail «not implemented yet». Другие ошибки остаются FAIL. `skip` для маскировки не используется.

## Замечания (не баги, решения разработчиков, которые тесты зафиксировали)

- **MockSearch.** С `domains=OFFICIAL_DOMAINS` по запросу «хлопок Чертаново» возвращает пусто. Официальные источники (МЧС, МВД, mos.ru) появляются только по гипотезам цепочки: «пожар автомобиля», «утечка газа», «полиция… поджог». Так задумано для демо CHAIN SEARCH.
- **Метрики.** Доли округлены до 4 знаков: 0.6667, а не 2/3.
- **Draft Acceptance Rate.** Учитываются только расследования, у которых есть правки редактора или которые дошли до ready/published. Черновик без правок в report_ready не считается. Тест под эту трактовку переписан.
- **Ошибка LLM в пайплайне.** Если MockLLM бросает `LLMError`, пайплайн пишет `progress.state=error`, статус остаётся researching. Для реального LLM срабатывает фолбэк на MockLLM.

## Что не покрыто

- MySQL (docker compose) — тесты только на SQLite.
- Реальные `AnthropicLLM` и `TavilySearchProvider` — нужны сеть и ключи.
- `MaxBotApiClient` проверен только на фейковом HTTP. Формат ответов Bot API помечен разработчиком как TODO(MAX).
- JS на странице (живой diff, подсветка claims, клик по утверждению) — проверено только наличие разметки, браузерных тестов нет.
- Права на «чужие» расследования между двумя продюсерами: ТЗ этого не ограничивает, тестов нет.
