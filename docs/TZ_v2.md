# NEWSFLOW AI — ТЗ v2 (замещает п.1, 2, 9 из TZ.md)

## Главное изменение
Сервис **только для редактора**. Ролей больше нет (продюсер, SMM, AI-оператор удаляются). Редактор в реальном времени ищет новую информацию по новостям, AI ему помогает, а когда новость подтвердилась и информации достаточно, **редактор сам передаёт её дальше** (кнопка «Передать дальше» → фиксируем куда/кому и комментарий; дальнейший процесс вне системы).

Всё остальное из TZ.md остаётся: MAX-домовые чаты, уникальность сообщений, телефоны авторов уникальных/важных сообщений («Кому позвонить» — теперь видит редактор), CHAIN SEARCH, справка из 9 разделов с источниками, Channel DNA, черновик, mock-режим без ключей.

## Пользователь и вход
- Один тип пользователя — редактор. Seed: 1–2 редактора (`editor`, `editor2`), пароль `demo`. Вход простой (или авто-вход для демо: `/login` с одной кнопкой «Войти как редактор»).
- Убрать `require_role`, enum ролей можно оставить только со значением editor или удалить; проверка только «залогинен».

## Статусы сюжета (investigation)
`new` → `researching` (AI ищет) → `review` (справка готова, редактор проверяет факты, звонит, правит текст; может перезапустить поиск/«копать глубже») → `handed_off` (Передано дальше) | `rejected` (Не подтвердилось). Из `rejected` можно вернуть в `review`. Все переходы делает редактор (кроме researching→review — система). История переходов сохраняется.

## Реальное время — главный экран «Радар»
- Живая лента входящих сообщений из подключённых чатов MAX (и новых web-находок) — обновляется без перезагрузки (SSE `GET /api/stream` или опрос раз в 3–5 с).
- Каждое сообщение: чат/район, автор, время, текст, бейджи «уникальное», «важное», «дубль ×N», «есть телефон».
- **Возникающие сюжеты** (emerging stories): система кластеризует свежие сообщения по теме (uniqueness-кластеры + ключевые слова/место) и показывает карточки «Возможный инфоповод: …, N сообщений из M чатов, первое в 14:31, растёт». Кнопка «Исследовать» → создаёт сюжет с зацепкой из кластера и запускает пайплайн.
- Также поле «Своя зацепка» — ручной ввод, как раньше.
- **Демо-трикл**: в mock-режиме сообщения сценария поступают постепенно (каждые ~10–30 с новое сообщение, первые ~10 уже есть при старте), чтобы жюри видело живой поток. После исчерпания — цикл с небольшими вариациями или остановка (на выбор, главное без падений). Кнопка «Перезапустить демо-поток» в настройках.

## Экраны
1. **Радар** (`/`) — лента + возникающие сюжеты + «Своя зацепка» + список моих сюжетов в работе.
2. **Сюжет** (`/stories/{id}`, старые `/investigations/{id}` → редирект) — одна рабочая страница редактора: живой прогресс поиска (цепочка гипотез), справка (9 разделов, отметка фактов подтверждён/не подтверждён/ложь), источники (дубли свёрнуты), «Кому позвонить» (телефоны, tel:), медиа, черновик (редактирование AI-текста прямо тут, diff с AI-версией, неподтверждённые утверждения подсвечены, клик → источник), кнопки «Копать глубже» (ещё итерация CHAIN SEARCH с доп. вопросом редактора), «Передать дальше» (модалка: кому/куда — свободный текст + выбор канала, комментарий; проверка: предупредить, если есть неподтверждённые факты), «Не подтвердилось».
3. **Сюжеты** (`/stories`) — список всех сюжетов с фильтром по статусу.
4. **Источники** (`/sources`) — подключённые чаты MAX (вкл/выкл, синк, район), профили каналов (Channel DNA).
5. **Статистика** (`/stats`, необязательно, маленькая) — сколько сюжетов передано/отклонено, среднее время от сигнала до передачи, traceability.

Удалить: экраны продюсера, SMM, пульт оператора, фидбэк «норм/стрём», доска по ролям.
