# NEWSFLOW AI — ТЗ v3: реальные данные (дополняет TZ_v2.md)

## Проблема
Сейчас всё синтетическое: сообщения MAX/Telegram — mock, web-поиск — mock, ссылки на источники ведут на несуществующие страницы.

## Требования
1. **Режим по умолчанию — реальные данные** (`DATA_MODE=live`). Синтетика остаётся только как `DATA_MODE=demo` (офлайн-подстраховка и тесты). В UI явно видно, какой режим включён.
2. **Реальный MAX.** Парсинг реальных публичных каналов/чатов MAX:
   - исследовать, что реально доступно: публичные страницы каналов MAX по ссылке (`https://max.ru/<name>`, `web.max.ru`, превью/встраивание), Bot API MAX (`platform-api.max.ru`, токен бота, бот добавлен в чат админом);
   - реализовать то, что работает без логина (если есть публичные веб-страницы каналов — парсить их, как `t.me/s/`); Bot API — для чатов, куда добавлен бот;
   - если без логина ничего нельзя — честно описать в docs и UI, что нужно (токен бота), и оставить Bot API как путь.
3. **Реальные ссылки на источники.** Web-поиск без платных ключей по умолчанию: Google News RSS поиск (`news.google.com/rss/search?q=…&hl=ru&gl=RU&ceid=RU:ru`) + RSS-ленты СМИ и официальных источников (мэрия Москвы, МЧС, ТАСС, РИА, Интерфакс и т.п. — только реально существующие URL лент, проверенные запросом). Tavily/Serper — опционально по ключу. Ссылка Google News должна приводить на статью (раскрыть редирект, если возможно; иначе оставить ссылку Google News — она рабочая). Ни одной выдуманной ссылки: всё, что показывается как источник, получено из реального ответа.
4. **Реальные Telegram-каналы по умолчанию** через web-preview `t.me/s/` (без логина) — стартовый набор из нескольких реальных публичных московских новостных каналов (проверенных, что превью доступно); Telethon — по ключам.
5. **Анализ без выдумок.** Без `ANTHROPIC_API_KEY` пайплайн работает экстрактивно: справка и черновик собираются из реальных найденных текстов (цитаты, даты, ссылки), без синтетических фактов про «Чертаново». С ключом — LLM, но каждое утверждение обязано ссылаться на реальный source_id.
6. **Источники: удаление** (кнопка + подтверждение; сообщения источника остаются в уже созданных сюжетах, но уходят из ленты) и **получение названия по ссылке**: при вставке ссылки/@username сервер сам определяет платформу и тянет реальное название канала/группы, аватар (если есть), число подписчиков, тип (канал/группа); показывается превью до добавления.
