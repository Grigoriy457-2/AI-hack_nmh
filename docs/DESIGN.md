# NEWSFLOW AI — дизайн-план (фронтенд v2)

## Бриф своими словами
Предмет: рабочее место одного редактора на ночной/дневной смене. Он смотрит, что пишут соседи в домовых
чатах MAX (Чертаново, Северное Бутово…), замечает, где несколько чатов заговорили об одном и том же,
отдаёт зацепку AI на проверку, звонит очевидцам, правит текст машины и **сам передаёт новость дальше**.
Аудитория: редактор (и жюри, которое тыкает 3–5 минут). Главная работа экрана — заметить новое раньше
других и не пропустить неподтверждённое.

Лексика предмета: адресная табличка дома (тёмно-синяя с белыми цифрами — так в Москве подписаны дома, и
так же «подписаны» домовые чаты), маркер-выделитель редактора (жёлтым отмечают то, что ещё надо
проверить), корректура (правка поверх чужого текста), дежурная смена, звонок очевидцу.

## 1. Первый план

**Цвет**
| Имя | Hex | Роль |
|---|---|---|
| Ночная смена | `#141C2B` | фон (тёмная тема) — глубокий чернильно-синий, не графит |
| Табличка | `#1F3A6B` | адресные таблички чатов/районов, активная навигация |
| Бумага | `#EEF1F5` | текст в тёмной теме, фон в светлой |
| Маркер | `#F4D23C` | всё новое и уникальное, неподтверждённое в черновике |
| Сирена | `#FF5D4F` | «важное», «ложь», «Не подтвердилось» |
| Сверено | `#5CCFA8` | подтверждённые факты, «Передано» |

**Шрифты** (только системные, без CDN)
- Заголовки, время, счётчики, бейджи: `Bahnschrift` (DIN-подобный гротеск Windows, вариативная ширина —
  берём SemiCondensed). Это шрифт дорожных и адресных знаков — прямо из лексики «табличка/диспетчерская».
  Фолбэк: `"DIN Alternate", "Roboto Condensed", "Arial Narrow", sans-serif`.
- Чтение (сообщения, справка, черновик): `"Segoe UI Variable Text", "Segoe UI", system-ui, -apple-system, Roboto, sans-serif`.
- Время — тем же Bahnschrift с `tabular-nums`, **не моноширинным**.

**Layout** — три колонки на десктопе, читаются слева направо как ход работы: сигнал → сюжет → действие.
```
┌ NEWSFLOW ─ Радар  Сюжеты  Источники  Статистика ─────── ● В эфире 12 чатов ─ ◐ ─┐
├──────────────────────────────┬────────────────────────┬─────────────────────────┤
│ Лента чатов          фильтр  │ Возникающие сюжеты     │ Своя зацепка            │
│ 14:31 [Чертаново Ц. д.12]    │ ┌ Хлопок на Варшавке ┐ │ [textarea]              │
│   Анна К.  уникальное  тел.  │ │ 9 сообщ. из 4 чатов │ │ Подставить пример       │
│   «Бахнуло так, что…»        │ │ первое 14:31 ▲ растёт│ │ [Исследовать]           │
│ 14:32 [ЖК Битца]  дубль ×3   │ │ [Исследовать]       │ ├─────────────────────────┤
│   …                          │ └─────────────────────┘ │ В работе                │
│ (новые вплывают сверху)      │ ┌ …                 ┐   │  #3 Хлопок… проверка    │
└──────────────────────────────┴────────────────────────┴─────────────────────────┘
```
Сюжет:
```
┌ ← Радар  Хлопок у жилого дома в Чертанове        [Проверка]   Копать глубже │ Не подтв. │ Передать дальше ┐
├────────────────────┬──────────────────────────────────────┬──────────────────────┤
│ Ход поиска         │ [Справка] [Черновик]                 │ Кому позвонить       │
│ 1 гипотезы…        │  9 разделов, у факта три отметки     │  Анна К. +7… tel:    │
│ 2 …                │  или черновик: правка + diff,        │ Источники (дубли ▸)  │
│ 3 …                │  маркер на неподтверждённом          │ Медиа (возм. старое) │
└────────────────────┴──────────────────────────────────────┴──────────────────────┘
```
Мобильный (375): одна колонка, сверху липкий переключатель разделов, действия сюжета — нижняя панель.
Выравнивание: всё по левому краю, числа справа в своих колонках, ничего не центрируется, кроме логина.

**Принципы**
1. Жёлтый маркер — единственная смелость: им отмечено только то, что новое/уникальное или ещё не проверено.
   Если жёлтого на экране нет — всё проверено.
2. Чаты подписаны как дома: синяя «адресная табличка» с районом.
3. Одна оркестрованная анимация — новое сообщение въезжает сверху и по нему проходит штрих маркера,
   который гаснет до жёлтой полосы слева. Плюс пульс «В эфире». Больше ничего не движется само.
4. Плотность диспетчерской: строки, а не карточки; панели отличаются фоном, а не рамками и тенями.

## 2. Ревизия плана против брифа и списка «типичных признаков AI-дизайна»

| Что было (в т.ч. в исходном брифе) | Признак | Что изменил и почему |
|---|---|---|
| Тёмный графит + один красно-оранжевый акцент | №2 (почти чёрный + один яркий vermilion) | Фон — чернильно-синий «ночная смена» `#141C2B`, а главный акцент — **жёлтый маркер редактора**, а не красный. Красный оставлен узко для «важное/ложь». Синий взят из московских адресных табличек — это предметный, а не дефолтный выбор. |
| Моноширинный шрифт для времени/метаданных | №5 (mono для мелких меток) | Время и счётчики — Bahnschrift с табличными цифрами. Выравнивание столбцом даёт то же, что mono, но без «терминального» штампа. |
| Бейджи и подписи КАПСОМ над блоками | №5, «all caps для меток» | Все подписи строчными, sentence case. Заголовки панелей — Bahnschrift полужирный, без надзаголовков-«eyebrow». |
| Мета через средние точки «Чат · автор · 14:31» | №5 | Мета разнесена по позициям: время — в левом столбце, чат — табличкой, автор — полужирным. Разделители не нужны. |
| Карточки сюжетов одинаковые, со скруглением 12 и тенью | №4 | Без теней. Радиусы по иерархии: табличка 3px, бейдж 4px, панель 10px, кнопка 8px. Возникающие сюжеты — не одинаковые карточки: высота строки «пульса» (полоска из точек-сообщений по времени) показывает, растёт ли сюжет. |
| «Исследовать →», «Открыть →» | №5 (→ в кнопках) | Кнопки называют действие без стрелок: «Исследовать», «Передать дальше». |
| Нумерация 01/02/03 в справке | структура как декор | Нумерация оставлена **только** в цепочке гипотез (это действительно последовательность итераций) и в хронологии (время вместо номера). Разделы справки — без номеров. |
| Подсказка жюри как баннер с градиентом | №4 | Подсказка — свёрнутая строка «Как пользоваться» в шапке колонки, раскрывается кнопкой, запоминается закрытой. |

После ревизии запоминающийся элемент один — жёлтый маркер (в ленте, в справке, в черновике), всё
остальное — спокойный синий и бумага.

## 3. Самокритика по скриншотам (что увидел и что поменял)
1. **Жёлтого было слишком много.** Бэкенд помечает «уникальным» почти каждое одиночное сообщение
   («Отдам котят» тоже). Маркер потерял смысл. Теперь жёлтая полоса и заливка бейджа — только
   у «уникальное И важное»; просто уникальное — тихий контурный бейдж.
2. **Лента шла не по времени** (порядок id ≠ время отправки при демо-потоке). Сортирую по `sent_at`,
   новое вставляется на своё место, сверху — самое свежее.
3. **Табличка чата с районом внутри не помещалась** и ломала строку автора. Район ушёл в title таблички.
4. **Карточки возможных сюжетов перерисовывались каждые несколько секунд** — кнопка «Исследовать»
   исчезала из-под курсора. Перерисовка только при реальном изменении данных.
5. **Кнопки отметки факта сжимали текст** в средней колонке. Отметки переехали под текст факта.
6. **Этапы поиска**: заметка справа сжимала название этапа — заметка теперь второй строкой.
7. **Модалка «Передать дальше»** с 7+ неподтверждёнными фактами вылезала за экран — список ограничен
   по высоте, модалка скроллится.
8. **Телефон (375px)**: навигация обрезала «Статистику» — убрал логотип-текст, ужал отступы; подсказка
   для жюри на телефоне по умолчанию свёрнута; переключатель колонок липкий, действия сюжета — нижняя панель.
9. Убрал «аксессуар»: на странице сюжета нижняя панель действий не показывается у переданных сюжетов.

## 4. Итерация v3 (реальные данные)
- **Режим данных в шапке.** «Реальные данные» — тихая кнопка с зелёной точкой; «Демо-данные» — пунктир и
  маркер-жёлтый фон: синтетика по смыслу «не проверено», поэтому тот же цвет. Рядом — «AI-анализ» /
  «Без AI: только цитаты». По наведению/тапу — поповер с объяснением и notes из `/api/mode`.
  На телефоне от кнопки остаётся одна точка, индикатор «В эфире» скрыт, чтобы влезла навигация.
- **RSS — третья платформа**, нейтральный знак «газетная полоса» (не оранжевые дуги RSS).
- **Добавление источника по ссылке:** превью (аватар, настоящее название, платформа, тип, подписчики)
  до сохранения; «Добавить» активна только после успешного превью. Технические префиксы ошибок
  (`TelegramSourceError:`) срезаются.
- **Удаление** — модалка с честным объяснением последствий, итог тостом, строка гаснет и исчезает.
- **Ссылки на источники** везде открываются в новой вкладке и подписаны доменом издания; без http-URL ссылка не рисуется.
- Самокритика по скриншотам: длинные RSS/TG-тексты раздували ленту → 4 строки + раскрытие по клику;
  автор = название канала дублировался → скрыт; «9,1 млн подписчик» → «подписчиков»; таблица источников
  на телефоне показывала голые числа → подписи у ячеек.
